Projects

These are projects I'm involved in.

Super Mario Galaxy 2: More Missions

Role: Creator

Mario gets trapped in another dimension.
He must go through 5 levels to help the starship.
SMG2:MM is a mod that started off my SMG2 modding path.


Super Mario Starshine

Role: Developer

Mario returns to a familiar tropical island.
For this project I made custom File Select Icons possible.
Other than that, I've helped on miscellaneous stuff.


Modular PTD

Role: Programmer

A modularized and improved version of Super Mario Galaxy 2: Project Template.
My modules: ChildSwitchArea, ExtTamakoro, FileSelectData, OSWReport


Whitehole Neo

Role: Programmer

The latest iteration of Whitehole. It adds tons of new features.
A decent chunk of the features are done by me (Creating galaxies, editing their properties, the new world map editor, JSONified shortcuts, etc.)
Check here for a bigger list of what I've done.


pyBRS

Role: Creator

A tool/library that enables making Rainbow Notes sequences out of MIDIs.
It features drag and drop scripts.
See its results in action here.


GalaxEyes

Role: Creator

GalaxEyes is a tool for Super Mario Galaxy 1/2 that optimizes and checks for issues in your mod.
It features:
Removing vanilla files from your mod
Merging identical collision codes
Resampling and re-encoding your ASTs to be more efficient
...and more!


pygapa

Role: Fork Creator

pygapa is a tool that edits Super Mario Galaxy 1/2 Effect.arcs.
This is a fork of the original tool by Aurum that adds bug fixes and particle editing.


J3DView

Role: Fork Creator

J3DView is a tool that edits and previews 3D models.
This is a fork of the original tool by blank63 that adds bug fixes.
